# OnScreenPrinter

写真に「印刷物の質感」を与えるブラウザツールです。ファッション誌のオフセット印刷、グラビア、新聞、リソグラフなどを、
分版（CMYK）→ 網点化 → 紙の上でのインキの重なり、という実際の工程に沿ってシミュレーションします。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・依存ライブラリなし・WebGL2 対応ブラウザが必要）。
画像はブラウザ内だけで処理され、外部には送信されません。

1. 「画像を開く」（複数選択可）、「フォルダを開く」、ドラッグ＆ドロップ、または貼り付けで写真を読み込む
2. プリセットを選び、右のパネルで調整する
3. サイズ（初期値は長辺 2048px）と形式（JPEG / PNG）を選んで「書き出し」で保存する
   （複数の画像は「すべて書き出し（zip）」で、同じ設定のまま zip にまとめて保存できます）

ホイール / ピンチで拡大、ドラッグで移動、ダブルクリックでフィット⇔等倍。
「元画像と比較」ボタン（またはスペースキー）を押している間は元画像を表示します。
スライダーの数値をクリックすると初期値に戻ります。
設定の変更は ↶ / ↷（Ctrl/⌘+Z、Ctrl+Y / ⌘+Shift+Z）で取り消し・やり直しでき、「設定をコピー」「貼り付け」で設定を文字として共有できます。

詳しい使い方は [manual.html](manual.html)（アプリ右上の「マニュアル」からも開けます）を参照してください。

## 配布用 zip の作成

```bash
scripts/build-dist.sh 1.0
```

`dist/OnScreenPrinter-v1.0.zip` ができます（アプリ本体・マニュアル・「はじめにお読みください.txt」入り）。
`dist/` は git の管理外です。

## 調整項目

| 区分 | 項目 |
| --- | --- |
| 印刷方式 | オフセット（AM網点）/ グラビア / FMスクリーン / 活版 / リソグラフ / 連続階調、線数、網点形状、スクリーン角度、ドットゲイン、版ズレ、インキのにじみ |
| 色味 | フルカラー / スミ1色 / ダブルトーン（特色）、インキセット、色温度、色かぶり、彩度、インキ濃度（全体・CMYK各版）、墨版の量（GCR）、色再現の補正 |
| トーン | 露出、コントラスト、ハイライト、シャドウ、フェード、シャープネス |
| 紙と質感 | ぼかし（網点をなじませる）、紙色（コート紙・上質紙・新聞紙など）、紙の質感、インキむら、粒状感、黒の浮き、むら・紙目の作り直し（乱数） |
| スキャン | オン/オフ、解像度（150/300/600dpi）、スキャナのぼけ |

「線数」は画像の幅あたりの網点数です。実際の雑誌（175線）は網点が肉眼でほぼ見えないため、
プリセットの線数は iPhone の画面いっぱいに表示して鑑賞する前提（170〜480）で決めてあります。
PC の大きな画面では同じ画像でも網点が大きく見えるので、その場合は線数を上げてください。

## スキャンの再現

「スキャン」をオンにすると、印刷した誌面をスキャナで取り込んだ画像を作ります。
画像の幅を A4 の幅（横長の画像は A4 横置き）に合わせ、指定した解像度の画素で、ガウスぼかしを掛けた網点を読み取ります。
網点とスキャナの画素が干渉してできる細かな模様や、網点がぼけて溶ける様子が出ます。

- 線数の表示にある「A4換算 ○線」が実際の印刷の線数です。雑誌は 150〜175 線が目安です
- 「スキャナのぼけ」は「紙と質感」の「ぼかし」に上乗せされます
- 書き出しはスキャン解像度そのまま（A4・300dpi なら幅 2480px）です

## 仕組み

- `js/renderer.js` — WebGL2 の2パス描画。パス1でトーン・色味補正と CMYK 分版、パス2で網点化と紙・インキの合成
  - 計算はリニアライト（反射率）で行い、網点面積率と明るさの関係を保つ
  - インキの濁りを見込んで CMY 量を解くため、補正を最大にすると色域内の色は元画像に近く再現される
  - ぼかしは網点をガウスでぼかした結果を式で直接求めるため、段差やざらつきが出ず、表示倍率にも左右されない
  - 網点は画像座標で定義されるので、プレビューの拡大率や書き出し解像度に依らず同じ絵柄になる
- `js/app.js` — UI、プリセット、表示操作、書き出し
- `js/zip.js` — 一括書き出し用の zip 作成（無圧縮・UTF-8 ファイル名、依存ライブラリなし）
- `js/sample.js` — 起動時のサンプル画像（手続き生成）

作業解像度は長辺 4096px まで（それ以上の画像は縮小して処理）、書き出しは長辺 8192px までです。
