OnScreenPrinter v{{VERSION}}
写真に、雑誌などの印刷物の質感を与えるツール

■ 使い方
1. このフォルダの中の「index.html」をダブルクリックします。
2. ブラウザ（Chrome / Edge / Safari / Firefox の最新版）が開きます。
3. 画像を開いて、プリセットを選び、調整して、PNG で書き出します。

詳しい使い方は「manual.html」をご覧ください（アプリ画面右上の「マニュアル」からも開けます）。

■ 注意
・インストールやインターネット接続は不要です。画像は外部に送信されません。
・フォルダ内のファイル構成は変えないでください（css・js・manual フォルダが必要です）。
・GPU を搭載した PC での利用を推奨します。iPhone・iPad では使えません。
